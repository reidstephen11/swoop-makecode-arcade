## Decisions made during the build (not Steve's, revisit if you disagree)

- **No splash screen.** It cost a keypress before play and truncated its own subtitle.
- **The crow glides rather than dives steeply** — a steep dive killed a stationary
  player in ~13 s, before a student had touched the D-pad.
- **Loot is a coin, key, gem and watch.** An earlier pink hair clip read as a heart.
- **The bucket is light blue, not wood** — brown vanished against the dirt.
- **Block positions in `main.blocks` are hand-set**, not MakeCode's auto-layout.
- **A sixth "STUCK?" card was added** to the five approved mission cards. It carries
  the toolbox colour map and the four failure modes, and is meant to stay face-up
  beside the laptop all session. It is the only card that is not a mission, and the
  only one that exists because of the one-adult/22-students constraint rather than
  because Steve asked for it — drop it if you disagree.
- **Card accent colour = the toolbox drawer colour** for that mission. This is the
  same "hunt by colour" mnemonic the STUCK card teaches.
- **The run sheet's timing table is labelled PROPOSED — NOT YET AGREED** on the page
  itself, because HANDOFF §3 was never signed off.

## Gotchas worth not rediscovering

- `SpriteFlag.AutoDestroy` destroys a sprite *created* fully off-screen on the next
  frame. Spawn flush with the edge (`x = -6`, `y = 0`), not beyond it.
- `game.onUpdateInterval` fires **immediately** on the first update, not after one
  period. The first crow arrives at t=0.
- A non-empty `README.md` in a MakeCode project pops an info panel over the workspace
  on load. Keep it a single space.
- The MakeCode simulator **stalls when the browser pane is hidden**. Any testing must
  use a headless browser with background throttling disabled.
- **The editor's DOM has two `.blocklyBlockCanvas` elements** — the flyout's is 0×0
  and comes first. `querySelector` returns the wrong one; filter by size.
- **The toolbox is `.blocklyTreeRoot`, not `.blocklyToolboxDiv`** in this build.
- **Card wording must be checked against the live toolbox, not from memory.**
  `tools/cardshots/toolbox-labels.mjs` dumps the real labels and defaults. It caught
  two errors: the Info drawer's `on score` block defaults to **100** (the card said 0),
  and `set scale to` is the **last** block in the Sprites drawer. Separately, the loot
  array's `⊕` is at the **bottom** of the block, not on its end.
- **WeasyPrint tables need `table-layout: fixed`** plus a width on every column, or a
  column with no explicit width collapses to one word per line.
- **A lone `+` between words is a line-break opportunity** in WeasyPrint and will be
  pushed onto its own line. Wrap it in `white-space: nowrap`.
- **This folder is a git repo nested inside another one.** The outer repo is
  `STEM Launchpad Session` and it still tracks its own copies of `.worklog.md` and
  `HANDOFF.md`; editing either shows as modified in *both*. Commit here, not there.
  The outer repo was deliberately **not** published — it carries the Raspberry Pi
  session's `TEACHER_ANSWER_KEY.md`, puzzle solutions, lockbox codes and the Pi
  account password, none of which should be public.
- **`swoop/built/` is gitignored** — 2.3 MB of MakeCode build output, regenerated by
  the editor and referenced by nothing in `tools/`.
